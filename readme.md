📱 Objetivo Principal

El objetivo principal de la materia Programación IV es el diseño, arquitectura y desarrollo móvil multiplataforma y nativo, abarcando tanto el desarrollo de aplicaciones para smartphones como la creación de los servicios backend y APIs robustas necesarios para su funcionamiento integral.

🚀 Tecnologías del Curso

A lo largo de este espacio académico, exploraremos y trabajaremos con las siguientes tecnologías clave:

Node.js: Entorno de ejecución para JavaScript orientada a la creación de aplicaciones de red escalables y servidores backend eficientes basados en eventos.

NestJS: Framework progresivo de Node.js para construir aplicaciones del lado del servidor (backend) altamente escalables, estructuradas y basadas en TypeScript mediante el uso de arquitectura modular, decoradores e inyección de dependencias.

React Native: Framework de desarrollo móvil creado por Meta que permite construir aplicaciones nativas reales para iOS y Android utilizando JavaScript y React, compartiendo la mayor parte de la lógica de negocio.

Kotlin: Lenguaje de programación moderno, tipado estático y totalmente interoperable con Java, utilizado principalmente como el estándar moderno para el desarrollo de aplicaciones Android nativas.

Dart: Lenguaje de programación optimizado para el desarrollo rápido de clientes en cualquier plataforma, creado por Google y utilizado como base principal para el ecosistema Flutter.

Flutter: Kit de desarrollo de interfaz de usuario de código abierto creado por Google para compilar aplicaciones compiladas de forma nativa para móviles, web y escritorio a partir de una única base de código escrita en Dart.
